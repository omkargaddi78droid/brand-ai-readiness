Zenith Metrics Setup FAQ

How long does Zenith Metrics setup usually take?

Zenith Metrics setup typically takes under fifteen minutes for a standard account, and most customers report finishing well within that window even when configuring several integrations at once during their very first session with the product on a completely fresh account.

Does Zenith Metrics support single sign-on during setup?

Zenith Metrics supports single sign-on for every enterprise account from the very first step of setup, letting an administrator configure identity provider settings before inviting any other team members to join the workspace or begin using any of the product's core features.

Can Zenith Metrics import data from a previous provider?

Zenith Metrics can import historical data from most common providers directly during setup, using a guided wizard that walks a new customer through mapping fields from their old system onto the equivalent fields inside Zenith Metrics before any data actually gets migrated over.

What happens if Zenith Metrics setup is interrupted partway through?

Zenith Metrics automatically saves setup progress at every step, so an interrupted Zenith Metrics setup session can always be resumed exactly where a customer left off without needing to repeat any earlier steps or re-enter any information that had already been provided previously.
